# مدیر جایزه روزانه LEME

این مخزن شامل نسخه‌ی آزمایشی برنامه‌ی اندروید برای مدیریت حساب‌های LEME است.

## وضعیت فعلی
- رابط فارسی با تم مشکی/طلایی
- ذخیره رمزگذاری‌شده‌ی حساب‌ها روی دستگاه با Android Keystore
- باز کردن سایت LEME داخل WebView
- بررسی تقریبی متن صفحه برای کمک به تشخیص وضعیت

**مهم:** ورود خودکار، کلیک خودکار روی دریافت جایزه و زمان‌بندی روزانه هنوز پیاده‌سازی نشده‌اند. بنابراین این نسخه را به‌عنوان ربات آماده یا نسخه‌ی نهایی استفاده نکنید. هیچ رمز عبوری را در GitHub یا گفتگو قرار ندهید.

## ساخت APK
از زبانه‌ی Actions، workflow با نام `Build Android APK` را اجرا کنید. پس از پایان موفق، فایل APK از بخش Artifacts همان اجرای workflow قابل دریافت است.

- حداقل Android: نسخه 8.0 (API 26)
- فایل خروجی: `app-debug.apk`
